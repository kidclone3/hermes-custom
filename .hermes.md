# Hermes Custom Project

This repository is the canonical source for the user's local Hermes and OpenCLI customizations. Runtime files are linked into `~/.hermes` and `~/.opencli`; mutable state and secrets remain there.

Use `uv run python3` for Python. Reusable cache-authored utility source belongs under `hermes/scripts/backfill/`; generated cache data remains outside Git. Never commit `.env`, raw email, Notion caches, tracking URLs, generated Obsidian notes, or runtime state. Verify with `bash tools/verify.sh`; add `--live` only for explicit runtime smoke testing.
